# INFO 7375 — Computational Skepticism for AI

**Predict → Build It → Use It → Ship It → Verify**

Fall 2026 course adaptation. Claude Code and Python are the working tools. Students build a small mechanism, use it on a concrete question, deliver evidence, and check whether the delivered result supports the claim. The book supplies the argument; the lessons turn it into practice.

**Claude Code access is assumed.** NEU students start at [Northeastern's Claude portal](https://claude.northeastern.edu/) and the [course prerequisites](prerequisites/README.md). Independent readers need their own Claude Code-enabled account. Python exercises run locally; direct API calls are optional, explicitly labeled, and may require separate credits.
