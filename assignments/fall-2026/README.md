Each rubric totals **60 implementation + 10 Frictional + 10 GitHub posting + 20 Relative Quartile**. Read the [NEU policies](../../prerequisites/README.md) before starting. Earlier briefs in the parent assignments/ directory remain historical resources; their point allocations do not apply here.

Submit a matching version to Canvas and the instructor-designated GitHub repository under fall-2026/first-name-last-initial/assignment-XX/. Include the final commit hash and folder URL in Canvas. Exact instructions are in [GitHub posting](../../prerequisites/github-submission.md). A private repository with reviewer access is acceptable where designated. Videos are optional and carry no separate points.
